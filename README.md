# FrameSage

FrameSage 是一款面向人像摄影现场的移动端 Web 拍摄辅助工具。它通过浏览器摄像头在本地读取单帧画面，以确定性规则分析光线与环境，再结合用户的相机、镜头和使用模式，给出可直接执行的参数、姿势、构图与避坑建议。

FrameSage 不替代摄影师做审美决定，也不将规则分析描述为云端 AI 识图。产品目标是让拍摄者在按下快门前，更快地完成现场判断与沟通。

## 规则引擎理论依据

- 参数换算以曝光三角、EV 曝光值体系、ISO 2720 与 18% 中性灰测光模型为理论基础。
- 手持安全快门采用摄影领域广泛使用的倒数法则（Reciprocal Rule），并为人像动作保留稳定余量。
- 人脸曝光优先、测光模式及曝光补偿策略来自职业人像摄影的通行现场方法。
- 参数冲突时默认优先保障快门，是 FrameSage 面向手持外景人像选定的工程策略，并非强制摄影公理；后续版本将支持用户自定义取舍权重。

FrameSage 不是经校准的独立测光表。复杂光线下应结合相机直方图和现场试拍复核推荐结果。

## 已实现的 MVP 能力

### 设备管理

- 内置 Sony、Canon、Fujifilm、Nikon 等常见机身与镜头预设。
- 支持手动录入品牌、型号、高感 ISO 阈值、动态范围、色彩倾向、焦段、最大光圈、虚化系数、最近对焦距离及备注。
- 支持多设备保存、切换、编辑和删除。
- 删除最后一台设备等边界状态有保护。

### 本地场景扫描

- 通过浏览器 `getUserMedia` 请求后置摄像头。
- 在本地 Canvas 中读取一帧，计算平均亮度、色温倾向、中心与边缘亮度差、局部亮斑、对比度和背景杂乱度。
- 通过确定性规则映射到以下 8 类场景：
  - 室内柔光
  - 室内混合光
  - 窗边逆光
  - 户外树荫光斑
  - 户外顺光
  - 户外侧光
  - 城市夜景暗光
  - 街景橱窗暖光夜景
- 展示环境亮度、光线方向、色温、背景杂乱度及大白话解释。
- 对非 HTTPS、无摄像头、权限拒绝、设备占用和启动超时提供明确提示。

### 手动模拟兜底

当设备或浏览器无法使用摄像头时，可以：

- 选择窗边逆光、室内柔光、城市夜景等环境预设。
- 手动调节亮度、色温、中心亮度差、局部亮斑、对比度和背景杂乱度。
- 运行与真实摄像头扫描相同的场景分类和推荐流程。

该能力也用于桌面演示、规则验证和自动化测试，不是静态占位页面。

### 参数推荐

纯函数规则引擎会结合当前设备、识别场景和指导模式，输出：

- 光圈
- 快门速度
- ISO
- 白平衡
- 曝光补偿
- 测光方式
- 对焦方式

当前规则覆盖逆光点测光与正曝光补偿、夜景 ISO 上限、安全快门与焦段关联、浅景深眼部对焦，以及缺失或异常镜头字段的安全降级。

- **新手模式**：突出最终参数和一句现场操作。
- **发烧友模式**：额外展示原理、取舍和风险。

### 姿势与构图

- 内置 24 套高质量方案种子，覆盖全部 8 类场景。
- 覆盖 35mm、50mm、85mm 焦段，以及三分法、居中、框架等构图方式。
- 每套方案包含头部、肩部、手部、脚部、视线、摄影师话术、构图和避坑说明。
- 根据场景、当前焦段和浅景深需求联动排序，展示最匹配的 3 套方案。
- 提供可视化构图辅助线覆盖层。

### 成套方案与收藏

- 在同一页面闭环展示场景分析、相机参数、姿势、构图和智能避坑提醒。
- 收藏时保存场景、设备、参数及姿势方案的完整快照。
- 收藏支持查看、编辑备注、删除和再次应用。

### 设置

- 新手模式与发烧友模式切换。
- 设备管理入口。
- 隐私说明。
- 清空全部 FrameSage 本地数据。

## 隐私与能力边界

FrameSage 采用 local-first 设计：

- 摄像头画面仅在当前浏览器中用于取一帧和 Canvas 指标计算。
- 不上传、不保存、不缓存用户照片或视频。
- 不调用云端图像识别服务。
- 场景识别是可解释的确定性规则判断，不是人脸识别，也不是云端生成式 AI。
- 设备、偏好和收藏数据仅保存在当前浏览器的 `localStorage`。
- 项目没有跨设备同步；清理浏览器站点数据后，本地内容会丢失。

## 摄像头与 HTTPS 要求

除 `localhost` 等浏览器认可的安全开发环境外，`getUserMedia` 通常只能在 HTTPS 页面中使用。

生产部署地址已经使用 HTTPS。若仍无法开启摄像头，请检查：

1. 浏览器是否支持 `navigator.mediaDevices.getUserMedia`。
2. 是否已允许网站使用摄像头。
3. 摄像头是否被其他应用占用。
4. 当前浏览器是否限制内嵌页面或企业环境中的摄像头权限。

摄像头不可用不会阻断产品体验，可直接使用“手动模拟扫描”。

## 本地开发

环境要求：Node.js 20 或更高版本，使用 pnpm。

```bash
pnpm install --no-frozen-lockfile
pnpm dev
```

开发服务器默认由 EdenX 启动。请以终端输出的地址为准。

## 检查、测试与构建

```bash
# 代码检查
pnpm lint

# TypeScript 类型检查
pnpm typecheck

# 场景分类、推荐规则和存储单元测试
pnpm test

# 生产构建
pnpm build

# 使用 EdenX 预览生产构建
pnpm serve
```

生产构建产物位于 `dist/`。EdenX 产物应使用框架提供的命令运行，不要自行搭建其他服务框架绕过 EdenX。

## 当前已知限制

- 场景分类依赖单帧统计指标，复杂光源、相机自动曝光或特殊色彩环境可能影响结果。
- 浏览器无法直接读取相机当前真实焦段、机身测光数据或 RAW 信息，设备参数由用户选择或填写。
- 当前按单一镜头焦段推荐，不支持变焦镜头实时焦段变化。
- 参数建议用于提高现场决策效率，不保证在所有机型和拍摄条件下形成完全一致的曝光结果。
- 数据仅存在当前浏览器的 localStorage，不支持账户同步、云端备份和多人共享。
- MVP 不包含修图、视频、社区、RAW 处理或照片上传。
- 当前构图辅助线覆盖三分、居中和框架等核心样式，更多构图模板可在后续版本扩展。
